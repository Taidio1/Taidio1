## 🤖 AI Engineering — beyond the chat interface

I'm interested in the engineering around AI: **connecting models to software, coordinating tools and agents, controlling actions, and making workflows observable and maintainable**.

Alongside public AI applications, I work on private projects. The case studies below intentionally describe the architecture at a high level; their source code is not public.

<details>
<summary><strong>Multi-Agent Orchestration Console</strong> — coordinating AI development workers</summary>

An experimental local control panel for coordinating Claude Code and Gemini CLI sessions. It provides task queues, worker status, live output, and supervision of long-running work.

**Engineering focus:** Agent orchestration, task lifecycle management, streaming status, automated tests, and failure handling.

**Technologies:** TypeScript, React, Fastify, WebSocket, SQLite.

*Private project — source code not shared.*

</details>

<details>
<summary><strong>Autonomous Agent with Guardrails</strong> — controlled tool execution via MCP</summary>

An agent-based automation system that separates model decisions from external actions through a controlled MCP integration layer.

**Engineering focus:** Tool permissions, execution limits, audit logs, simulation modes, monitoring, and containerized deployment.

**Technologies:** LLM APIs, MCP, Python, Docker.

*Private project — source code and operational details not shared.*

</details>

<details>
<summary><strong>Market Intelligence Assistant</strong> — LLM-supported information filtering</summary>

An engineering research project focused on filtering market information against a tracked portfolio and summarizing relevant events with LLM assistance.

**Research focus:** Data ingestion, relevance filtering, grounded summaries, sentiment signals, and evaluating information quality — not predicting investment returns.

*Private research project — work in progress.*

</details>
